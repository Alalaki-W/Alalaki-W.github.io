1.1.1 学习范式与策略框架（IL / RL / VLA / Diffusion Policy / World Model）

  • 行为克隆（Behavior Cloning, BC）：把控制当成监督学习：输入观测/指令，输出动作。优点是数据友好、上手快；缺点是分布外脆弱（covariate shift），需靠干预/DAgger/重置策略兜底。
  • 逆强化学习（Inverse Reinforcement Learning, IRL）/偏好学习：先学”奖励/偏好”，再用 RL 求策略；泛化好，但链路长、训练贵。
  • GAIL / 对抗模仿：通过判别器让”机器人轨迹像专家”，绕开显式奖励建模。对抗稳定性与探索机理是工程挑战。
  • 离线 RL / 在线 RL / Offline-to-Online（O2O）：离线：全靠静态数据、安全可控；在线：探索充分但要解决安全与成本；O2O：先离线”站起来”，再在线”走起来”，符合工程常识。
  • 层级策略（Hierarchical Policy）：高层做子目标/技能编排（options / behavior trees / task graphs），中层学习原子技能，低层用跟踪控制/安全壳执行。
  • VLA（视觉–语言–动作, Vision–Language–Action）：从视觉–语言模型（VLM）微调到端到端控制：看图、听指令、输出动作，同步提升开放词汇与长时序任务能力。
  • 扩散策略（Diffusion Policy）：用生成模型在轨迹/动作分布上采样，天然平滑、抗噪，易接视觉/语言条件；部署时注意采样延迟与实时间隔对齐。
  • 世界模型（World Model, WM）：学习”可微的环境动态”，在潜空间里做规划/MPC/RL，把昂贵的真机交互换成”脑内演练”；关键在表征学习、模型偏差控制、闭环落地。
  • 残差学习与模型融合：用 MPC/几何控制做”主干”，RL/IL 学残差/补偿（摩擦、柔顺、延迟、未建模动力学），在工业里很常见。
  • 安全壳（Safety Shield）：策略外层的速度/力矩限幅、碰撞守卫、紧急制动与可达性过滤，用于上线阶段风险控制与可解释合规。

    • 1. 行为克隆（Behavior Cloning, BC）

      核心本质：把机器人控制变成最朴素的监督学习——“专家怎么做，我就怎么做”

      • 输入：机器人看到的画面 / 传感器数据 / 人类指令（观测）
      • 输出：机器人每个关节的角度 / 速度 / 力矩（动作）
      • 训练数据：人类专家手把手演示的 “观测 - 动作” 配对数据

      最直观的例子：教机械臂倒水

      1. 人类拿着机械臂的末端，演示 100 次 “从桌子上拿起杯子→倾斜→把水倒进碗里” 的完整过程
      2. 全程记录：每个时刻摄像头拍到的画面（观测）+ 机械臂 6 个关节的角度值（动作）
      3. 训练一个神经网络：输入画面，直接输出对应的关节角度
      4. 部署后：机械臂看到杯子，就会自动输出和专家一样的动作序列

      优缺点的真实含义：

      • ✅ 优点：数据友好、上手最快—— 不需要懂奖励函数、不需要复杂的 RL 调参，有演示数据就能跑，是所有机器人项目的入门基线
      • ❌ 缺点：分布外脆弱（Covariate Shift）—— 这是 BC 的致命问题
        • 比如专家演示时杯子永远在桌子正中间，训练好的机器人遇到杯子在角落，就会完全懵掉
        • 因为它只学了 “看到中间的杯子就抬胳膊 30 度”，没学过 “看到角落的杯子该怎么办”
        • 一旦机器人的动作稍微偏离专家轨迹，后续的观测就会越来越离谱，最终彻底失败

      常见补救方案：

      • DAgger：让机器人自己先跑，跑错的地方人类实时纠正，把纠正后的 “观测 - 动作” 数据加进去重新训练
      • 重置策略兜底：如果机器人偏离轨迹超过阈值，就自动把它拉回初始状态重新来

2. 逆强化学习（IRL）/ 偏好学习

核心本质：BC 学的是 “专家做了什么动作”，IRL 学的是 “专家为什么这么做“—— 先推断出专家的目标（奖励函数），再用 RL 让机器人自己学会实现这个目标

对比 BC 的例子：还是倒水任务

  • BC：学 “看到杯子在 x=0.5m，y=0.3m，就输出关节角度 [10°,25°,…]”
  • IRL：先看 100 次专家倒水的视频，自己推断出：
    • 奖励函数 = 水倒进碗里 +100 分，洒出来 1 滴 -5 分，杯子倒了 -1000 分，动作越快 +1 分
  • 然后用强化学习让机器人自己在仿真里反复尝试，最大化这个奖励函数

优缺点的真实含义：

  • ✅ 优点：泛化能力强—— 只要奖励函数对了，杯子换颜色、换形状、换位置，机器人都能学会倒水
  • ❌ 缺点：链路长、训练贵
    • 第一步 “学奖励函数” 就很难：专家的很多偏好是隐性的（比如 “不能洒到桌子上”），很难从轨迹里准确推断
    • 第二步 “用 RL 训练策略” 本身就需要大量算力和时间，还容易训练崩溃

偏好学习（IRL 的简化版）：

  • 不用收集完整的专家轨迹，只要人类给两个机器人的轨迹打分：”A 比 B 做得好”
  • 比如机器人倒了两次水，一次洒了一点，一次没洒，人类说 “第二个更好”
  • 模型就能从这些成对的偏好里学习奖励函数，大大降低了数据收集成本

3. GAIL / 对抗模仿

核心本质：用GAN（生成对抗网络）的思路做模仿学习，绕开了 “显式写奖励函数” 和 “显式学奖励函数” 这两个难题

  • 生成器：机器人的策略，输出动作轨迹
  • 判别器：判断一条轨迹是 “专家演示的” 还是 “机器人生成的”
  • 训练目标：生成器要尽量骗过判别器，判别器要尽量分清楚真假

例子：教机械臂开门

  1. 收集 50 条人类专家开门的轨迹
  2. 让机器人随机生成开门轨迹，判别器来区分
  3. 生成器不断调整自己的动作，让判别器越来越分不清
  4. 当判别器准确率降到 50%（瞎猜）时，机器人的开门轨迹就和专家几乎一样了

优缺点的真实含义：

  • ✅ 优点：不用写奖励，也不用学奖励，直接模仿专家轨迹的分布，效果通常比纯 BC 好
  • ❌ 缺点：对抗训练极不稳定，工程挑战巨大
    • 很容易出现 “模式崩溃”：机器人只会开一种特定位置、特定把手的门，其他门都不会
    • 训练过程像坐过山车：前 1000 步还开得很好，第 1001 步突然就完全不会了
    • 工业界很少直接用纯 GAIL，通常会和 BC、RL 结合使用

4. 离线 RL / 在线 RL / Offline-to-Online（O2O）

这三个是机器人策略训练的三种基本模式，解决的是 “机器人在哪里学习” 的问题

在线 RL（Online RL）

核心本质：机器人直接在真实世界 / 仿真里试错学习，做对了给奖励，做错了给惩罚

  • 例子：DeepMind 的机械手玩魔方，就是纯在线 RL 练出来的 —— 机械手自己随便转魔方，转对了给奖励，转错了惩罚，练了几百万次终于学会了
  • ✅ 优点：探索充分，能发现人类专家都想不到的最优策略
  • ❌ 缺点：安全风险极高，成本极贵
    • 真实机械臂乱挥可能砸到人，试错一次可能摔坏几百块的工件
    • 训练一个简单的抓取任务，可能需要在真机上跑几十万次，耗时几个月

离线 RL（Offline RL）

核心本质：机器人不碰真机，只用别人已经收集好的静态数据集训练

  • 例子：有一个公开数据集，里面有 100 万条各种机器人抓取不同物体的轨迹，直接用这些数据训练你的抓取策略
  • ✅ 优点：安全、便宜、速度快—— 不用真机，用 GPU 跑几天就能训练好
  • ❌ 缺点：上限被数据集锁死
    • 机器人永远学不到比数据集里更好的策略
    • 如果数据集里有坏数据（比如专家也抓失败的轨迹），机器人也会学坏

O2O（Offline-to-Online，离线转在线）

核心本质：现在工业界最主流、最实用的工程方案—— 先离线 “站起来”，再在线 “走起来”

  1. 第一步：在海量公开数据集 + 自己收集的离线数据上预训练一个基础策略，让它至少能完成基本动作（比如先离线学会怎么抓杯子）
  2. 第二步：把这个基础策略放到真实机器人上，做少量的在线微调（比如只跑 1000 次），优化细节（比如调整抓力，避免捏碎纸杯）
  • ✅ 完美结合了两者的优点：用离线数据降低成本和风险，用在线微调提升泛化性和性能
  • 例子：波士顿动力、特斯拉 Optimus、Google DeepMind 的机器人，几乎全都是用 O2O 模式训练的

5. 层级策略（Hierarchical Policy）

核心本质：把复杂的长时序任务拆成多层，解决 “单个神经网络学不会复杂任务” 的问题

  • 人类做复杂任务也是分层的：比如 “去厨房拿可乐”，你不会直接想 “我的左腿该抬多少度”，而是先拆成大步骤，再逐步细化

最经典的三层架构 + 例子：让人形机器人 “去厨房拿一瓶冰可乐”

层级 职责 具体做什么 常用技术
高层（任务规划层） 做子目标编排 把大任务拆成：1. 走到冰箱前 2. 打开冰箱门 3. 找到可乐 4. 拿起可乐 5. 关上冰箱门 6. 走回客厅 大语言模型（LLM）、行为树、任务图
中层（技能层） 学习原子技能 每个子目标对应一个可复用的技能：- “走到冰箱前”= 导航技能- “打开冰箱门”= 开门技能- “拿起可乐”= 抓取技能 BC、RL、扩散策略
低层（控制层） 精确执行动作 控制每个关节的角度、速度、力矩，保证动作平稳，避免抖动 PID、MPC、传统机器人控制

核心优势：

  • 技能可以复用：”开门” 技能学会了，以后可以用来开柜门、开房门、开汽车门
  • 调试简单：如果机器人拿可乐失败了，你可以单独看是 “导航错了” 还是 “开门没开好”，不用去调整个大模型
  • 是目前唯一能让机器人完成超过 10 步以上长时序任务的方法

6. VLA（视觉 - 语言 - 动作，Vision-Language-Action）

核心本质：大模型时代机器人的革命性突破—— 把视觉 - 语言模型（VLM）加一个 “动作头”，变成能直接输出机器人动作的端到端模型

  • 以前的机器人：只能执行固定指令，比如 “抓取红色杯子”，说 “帮我拿那个能喝水的东西” 就听不懂了
  • VLA 机器人：能理解人类的自然语言指令，能看懂复杂的视觉场景，直接输出动作

最典型的例子：Google RT-2 模型

  • 输入：一张房间的照片 + 人类指令：”帮我把那个脏了的杯子扔到蓝色垃圾桶里”
  • 模型内部：VLM 先理解 “脏了的杯子” 是什么，找到它的位置，再理解 “扔到垃圾桶” 是什么意思
  • 输出：机械臂的 7 个关节的动作序列，直接控制机械臂完成整个任务

优缺点的真实含义：

  • ✅ 优点：开放词汇能力 + 长时序能力
    • 不用每个任务都重新训练：你可以让它拿杯子、拿书、拿钥匙，只要语言能描述，它就能尝试
    • 能处理多步任务：”先把桌子上的书放到书架上，然后把垃圾倒掉，再给我倒一杯水”
  • ❌ 缺点：动作精度不够，推理速度慢
    • 现在的 VLA 还做不了精细的装配任务（比如拧螺丝、插排线），误差通常在厘米级
    • 大模型推理一次需要几百毫秒，对于高速运动的机器人来说延迟太高

7. 扩散策略（Diffusion Policy）

核心本质：把生成图像的扩散模型用到机器人上，用来生成平滑、连续的动作轨迹

  • BC 学出来的动作通常是断断续续的，因为专家演示的轨迹有噪声
  • 扩散模型擅长生成 “符合某种分布的平滑数据”，正好适合生成机器人的动作轨迹

例子：教机械臂画一个爱心

  1. 收集 100 条人类画爱心的轨迹数据
  2. 训练一个扩散模型：输入条件 “画爱心”，输出一条完整的、平滑的轨迹
  3. 部署时：给模型输入 “画爱心”，它就会生成一条没有抖动、非常流畅的轨迹，机械臂跟着走就能画出完美的爱心

优缺点的真实含义：

  • ✅ 优点：
    • 天然平滑、抗噪：生成的动作没有抖动，即使摄像头有模糊、传感器有噪声，也能输出合理的动作
    • 易接多模态条件：可以很方便地接视觉条件（输入一张猫的图片，生成画猫的轨迹）、语言条件（输入 “画一个圆”）
  • ❌ 缺点：采样延迟高
    • 原生扩散模型需要 10-50 步采样才能生成一条轨迹，推理一次需要几十到几百毫秒
    • 对于需要 100Hz 以上实时控制的机器人（比如高速装配机械臂）来说，延迟是致命的
    • 现在的工程解决方案：用知识蒸馏把多步采样变成 1-2 步，大幅降低延迟

8. 世界模型（World Model, WM）

核心本质：让机器人拥有 “想象力”—— 学习一个 “可微的环境模拟器”，在脑子里先 “预演” 一遍动作，再到真实世界执行

  • 人类的大脑就是一个完美的世界模型：你伸手拿杯子之前，脑子里会先模拟一下伸手的过程，预判杯子会不会倒，会不会碰到旁边的东西

工作流程 + 例子：教机器人叠衣服

  1. 先让机器人看几百万次衣服运动的视频，训练世界模型：
    • 输入：当前衣服的状态 + 机器人的动作
    • 输出：100 毫秒后衣服会变成什么样子
  2. 机器人要叠衣服时，先在世界模型里 “脑内演练”：
    • 我先做动作 A，衣服会变成状态 1
    • 再做动作 B，衣服会变成状态 2
    • … 直到找到能把衣服叠好的最优动作序列
  3. 最后只需要把这个最优序列在真实世界执行一遍就行

优缺点的真实含义：

  • ✅ 优点：把昂贵的真机交互换成便宜的脑内演练
    • 以前要在真机上试 100 万次，现在在世界模型里试 100 万次，只需要在真机上试 100 次验证
    • 特斯拉 Optimus 就是这么做的：在仿真世界里训练了数十亿次，真机上只需要少量微调
  • ❌ 缺点：模型偏差是最大的挑战
    • 世界模型很难学准复杂的动态：比如液体的流动、布料的褶皱、软物体的变形
    • 如果模型预测有一点点偏差，脑内演练的完美结果在真机上就会彻底失败
    • 现在的研究重点：怎么控制模型偏差，怎么把模拟好的策略闭环落地到真机

9. 残差学习与模型融合

核心本质：工业界的 “真香定律”—— 纯学习的方法不可靠，传统控制的方法不灵活，那就把两者结合起来

  • 用传统控制（MPC / 几何控制 / PID）做主干，保证基础的精度和可靠性
  • 用BC/RL 学残差，补偿传统控制无法建模的误差

最常见的工业例子：焊接机器人

  • 传统 MPC：能让机械臂沿着预设的焊缝走，精度达到 0.1mm，非常可靠
  • 但是：如果工件有一点点变形，或者焊缝位置有 0.2mm 的误差，传统 MPC 就焊不准了
  • 残差学习方案：
    1. 传统 MPC 输出一个基础动作：a_base
    2. RL 模型输出一个残差动作：Δa（用来补偿焊缝的误差）
    3. 最终执行的动作：a = a_base + Δa

为什么工业界最爱这个方案：

  • 90% 以上的工业机器人应用都是这么做的
  • 传统控制的部分是可解释、可预测、安全的
  • 学习的部分只负责小范围的补偿，即使学错了，也不会出大问题
  • 完美解决了 “纯学习方法不可靠、纯传统方法不灵活” 的矛盾

10. 安全壳（Safety Shield）

核心本质：所有机器人上线的最后一道防线—— 不管你用什么学习方法，外面都必须套一个安全壳

  • 安全壳是独立于策略之外的硬约束，优先级最高：如果策略输出的动作不安全，安全壳会直接否决它，输出一个安全的替代动作

安全壳的四大核心功能：

  1. 速度 / 力矩限幅：限制机械臂的最大速度不能超过 1m/s，最大力矩不能超过 10N・m，防止伤人
  2. 碰撞守卫：用传感器检测周围的人和物体，如果距离小于 0.5 米自动减速，小于 0.1 米紧急制动
  3. 可达性过滤：如果策略输出的动作会让机器人撞到桌子、墙或者自己，直接过滤掉
  4. 紧急制动：任何时候按下急停按钮，机器人会立刻断电停止

为什么必须有安全壳：

  • 学习出来的策略是黑盒，你永远不知道它什么时候会输出一个危险的动作
  • 安全壳是可解释、可验证的，符合工业安全法规
  • 出了事故可以追责：”机器人停了是因为检测到有人靠近”，而不是 “模型不知道为什么抽风了”
