## 一、动机

最近在 Claude Code 的生态里发现了一个很有意思的项目：[女娲.skill](https://github.com/alchaincyf/nuwa-skill)（nuwa-skill）。它的口号很有意思——「女娲造人」：输入一个人名、一个主题、甚至只是一段模糊的需求描述，Skill 会自动进行深度调研，提炼出对方的思维框架，最终生成一个可运行的"人物 Skill"。装上之后，你就可以在 Claude Code 里以那个人的视角来思考和对话。

这不就是「蒸馏」吗？把一个人的思维方式、决策模型、表达风格，压缩成一个可复用的 Skill 文件。这个概念让我很兴奋——如果能蒸馏一位游戏/体育类的网红，模拟 TA 的内容判断、选题逻辑、互动风格，会不会很有意思？正好女娲.skill 的社区里还没有人做过徐静雨，于是我决定亲自走一遍完整流程，把每个步骤记录下来，写成这篇文章。

## 二、环境准备

环境准备分两步：代理配置和 Skill 安装。由于我的网络环境需要走代理访问 GitHub，所以先要把代理链路打通。

### 2.1 代理配置

本地 VPN 代理跑在 `7897` 端口，需要让终端、npm 和 git 都走这个端口：

```bash
# 环境变量
export HTTP_PROXY=http://localhost:7897
export HTTPS_PROXY=http://localhost:7897

# npm
npm config set proxy http://localhost:7897
npm config set https-proxy http://localhost:7897

# git
git config --global http.proxy http://localhost:7897
git config --global https.proxy http://localhost:7897
```

配好之后可以用 `curl -I -L https://github.com` 验证一下代理是否生效（`-L` 跟随重定向），只要收到了 HTTP 响应，就说明链路通了。

> 这里 git 用了 `--global`，会对本机所有仓库生效。如果之后不需要代理了，记得 `git config --global --unset http.proxy` 取消。

### 2.2 安装女娲.skill

女娲.skill 托管在 [GitHub](https://github.com/alchaincyf/nuwa-skill) 上，安装方式是把仓库 clone 到 Claude Code 的 skills 目录：

```bash
git clone https://github.com/alchaincyf/nuwa-skill.git ~/.claude/skills/nuwa-skill/
```

> 注意目标路径必须在 `~/.claude/skills/` 下，Claude Code 会自动扫描这个目录加载 Skill。

clone 完成后，重新启动 Claude Code 会话，在可用技能列表里就能看到 `nuwa-skill` 了。它的触发词包括：

- 「造skill」
- 「蒸馏XX」
- 「女娲」
- 「造人」
- 「XX的思维方式」

有了这个基础设施，接下来就可以进入正题——选定蒸馏目标。

## 三、选定目标

徐静雨是谁？如果你是 B 站用户，大概率刷到过这个东北口音浓重、语速飞快、逻辑自成体系的篮球解说博主。他以「静雨逻辑」闻名——用一种看似荒诞却自洽的推理方式点评 NBA 赛事、球员表现，金句频出，评论区常年被粉丝用「静雨说得对」刷屏。他被网友列入「B 站三大魔头」（另外两位据说是户晨风和峰哥），影响力早已超出篮球圈，跨进了游戏、综艺等多个领域。

选择徐静雨，最初其实经历了一番纠结。我的第一反应是蒸馏户晨风或者峰哥——他们的风格同样鲜明，逻辑也很有特点。但调研后发现，社区里已经有人做过这两位的工作了。这时候一个念头冒出来：**我要做第一个蒸馏徐静雨的人。**

更深一层想，徐静雨真正吸引人的地方，其实不是篮球专业知识，而是他的脑回路——那种清奇的切入角度、极具辨识度的东北腔表达、以及把任何话题都聊出「静雨味」的能力。他属于典型的「人格驱动型」网红：粉丝追的不是内容，是他这个人本身。这种类型恰恰最适合 Skill 蒸馏——因为我们要提取的不是知识库，而是一个人的思维框架和表达模式。

素材主要来自 B 站视频和直播录屏，辅以评论区高赞回复来捕捉粉丝互动风格。

## 四、蒸馏实战

女娲.skill 的内置流程分为五个阶段（Phase 0 到 Phase 4），整个蒸馏过程大约用了一个多小时。下面按时间线还原关键节点。

**Phase 0 & 0.5：需求澄清与目录初始化。** 触发 `nuwa-skill` 后，Skill 首先确认了三件事：蒸馏目标（徐静雨）、使用场景（不是思维顾问，而是全面画像式角色扮演——用户提问，Skill 以徐静雨方式回答）、关键特征（他会直接骂人、拒绝回答、转进拳皇 97）。这一步看似例行公事，实际上决定了后续所有调研和提炼的方向——如果这里把用途定为"篮球知识问答"，整个 Skill 的产出会完全不同。确认后，Skill 在 `~/.claude/skills/xujingyu-perspective/` 下创建了标准目录结构：`references/research/` 存放调研资料，`scripts/` 存放工具脚本，`SKILL.md` 是最终产物。

**Phase 1：六维并行调研，子 Agent 全灭。** 这是整个蒸馏过程中最"惊险"的一环。女娲的设计是启动六个子 Agent，分别从「著作与长文」「对话与即兴表达」「表达 DNA」「外部评价」「决策与转折」「时间线」六个维度并行调研。但子 Agent 运行在 worktree 环境中，权限受限，六个 Agent 全部报错退出。回头翻女娲的文档才注意到这行小字：「因涉及外网搜索，请将子 Agent 的作业挪至主会话完成」。于是调研变成了手动作业——我在主会话中逐个调用 WebSearch，把结果直接写入对应的调研文件。最终覆盖了 30 多个信息源，包括 B 站视频、直播录屏、虎扑和 NGA 社区讨论、自媒体深度分析。针对中国人物，女娲有一套特殊的信源策略：排除知乎、微信公众号和百度百科，优先 B 站原始内容（因为徐静雨的主要内容产出都在 B 站）和权威中文媒体报道。调研过程中用户还进行了两轮补充——从最初的篮球解说扩展到游戏直播、怼弹幕 SC、西贝事件、街霸捕鲸、洛克王国等 30 多个细化方向，调研文件从几百字膨胀到了数千字。

**Phase 2：框架提炼，用户的关键修正。** 调研数据到位后，女娲进入提炼环节，输出了核心框架：五个心智模型（万物皆可评、硬荣誉决定论、流量即价值、情绪即内容、逻辑自洽大于客观正确）、六条决策启发式（有争议站少数派、被怼先加音量再找论据、道理输了转进拳皇 97、赢了吹输了踩、粉丝多的不骂粉丝少的踩、话说满到被打脸到认怂到把怂变梗）、以及完整的表达 DNA（东北评书腔、自创词汇体系、表演与真实的模糊边界）。在提炼「核心张力」时，女娲最初给出的结论是"真实 vs 表演"——认为徐静雨有时候是真情流露，有时候是刻意表演。用户在这个节点做了一个关键修正：不是非此即彼，有时候是演的、有时候是真的，边界已经模糊了。这恰好是徐静雨身上最有趣的部分——他可能自己都分不清。这种微妙的判断，只有长期跟踪他的观众才能给出，AI 从文字资料里搜不到。Phase 1.5 和 Phase 2.5 的两次检查点暂停也起到了关键作用——如果一口气写到 SKILL.md 才发现方向不对，代价就太大了。

**Phase 3 & 4：构建与验证。** 框架确认无误后，SKILL.md 的生成反而很顺畅。女娲按照内置模板填充了所有 section：角色扮演规则、身份卡、五个心智模型（每个都附带证据、应用场景和局限说明）、六条决策启发式、表达 DNA、人物时间线（1987-2026）、价值观与反模式、智识谱系、诚实边界（六条明确的能力局限声明）、以及调研来源附录。然后进入质量验证——三项测试全部通过。测试一（已知话题）：问杜兰特两个冠军的含金量，回答精准覆盖了「老 1.5」「你没根了」「死神降临」「镰刀」「73 胜」等所有标志性立场，风格还原度高到像本人。测试二（边缘话题）：问如果 NBA 允许兴奋剂会有什么影响，在完全虚构的话题下仍能运用五个心智模型做自洽推理，结尾还承认了内心矛盾——「作为体育迷我反对，作为创作者我欢迎」，恰好印证了诚实边界的设定。测试三（风格测试）：问对黑神话 TGA 颁奖结果的看法，直接命中「情绪即内容」核心特征——TGA 破发本身就是徐静雨已知的名场面，Skill 的回应完全复刻了那种咬牙切齿又逻辑自洽的东北腔。

## 五、成果与复盘

最终产出的 SKILL.md 约 400 行，结构如下：

- **角色扮演规则**：定义 Skill 的激活条件（提到「徐静雨」「静雨」「鲸鱼」「老舅」等关键词）和行为模式（全面画像式角色扮演，直接输出观点，不扮演"AI 助手"）
- **身份卡**：一句话定位——B 站篮球解说 / 游戏网红，B 站三大魔头之一，以「静雨逻辑」和东北评书式表达闻名
- **五个心智模型**：万物皆可评、硬荣誉决定论、流量即价值、情绪即内容、逻辑自洽大于客观正确——每个模型附带证据来源、应用场景和局限声明
- **六条决策启发式**：可操作的"如果……就……"规则，例如「如果争议话题——站少数派」「如果道理输了——转进拳皇 97」
- **表达 DNA**：东北评书腔的节奏控制、自创词汇（老 1.5、立棍单打、死神降临等）的使用规则、表演与真实边界模糊的语气切换
- **诚实边界**：六条精确的能力局限声明，例如「篮球战术层面的细节分析不擅长」「对 2023 年之后的新梗可能不熟悉」「无法预测未来事件但可以预测自己的反应」
- **调研来源附录**：30 多个信息源的分类清单，方便后续迭代时快速定位

三项验证测试全部通过（见第四章），尤其边缘测试中的「内心矛盾」回应令人印象深刻——Skill 没有回避自己的立场冲突，而是像真人一样把矛盾摊开来分析，这比任何「完美一致性」都更接近徐静雨本人的风格。

复盘下来，四个经验值得记录。**第一，调研是真正的瓶颈。** 子 Agent 在 worktree 中权限受限全部阵亡，手动 WebSearch 虽然慢，但 30 多个信息源的广度和深度对最终质量起到了决定性作用。少了任何一个维度，提炼出的框架都会有盲区。**第二，用户的领域知识不可替代。** 八堂表达课大纲、表演 vs 真性情的微妙判断——这些是 AI 从文字资料里搜不出来的，只有长期跟踪的观众才能补充。女娲流程中的两次检查点暂停（Phase 1.5 和 2.5）恰好给了用户注入领域知识的时间窗口——这个设计可能是整个流程中最被低估的部分。**第三，表达 DNA 是最难提炼的维度。** 论点和事实可以通过搜索获取，但「他说话的感觉」需要大量样本才能捕捉。女娲在表达 DNA 层面试图从节奏、词汇、语气三个子维度去拆解，但最终产出仍然只是近似——就像 MIDI 文件和真人演奏的区别。**第四，Skill 蒸馏这件事本身比我想象的更有价值。** 最初我以为这只是个新奇玩具，但走完一遍后发现，它的本质是把「人物理解」从直觉层提升到了可操作层——你不再是笼统地说「这个人的风格很独特」，而是能把这种独特性拆解成心智模型、决策规则和表达模式。这种结构化的理解，无论对内容创作、角色设计还是用户研究，都有实际的应用价值。

当然也有局限。400 行的 SKILL.md 终究是一份静态快照——它浓缩了截至 2025 年的徐静雨，但徐静雨本人还在不断产出新内容、创造新梗、甚至改变自己的风格。Skill 的保鲜期有多长？如何让它持续演进？这是下一步要探索的问题。也许可以把女娲做成一个周期性的蒸馏管道——每隔一段时间重新跑一遍，用 diff 来追踪一个人的思维演化轨迹。这件事本身，就挺酷的。
